# 📊 Сравнение методов детектирования движений

## Полная таблица сравнения

| Критерий | v2.4 All Points | v3.0 Swing Detection | **v4.0 Kalman Filter** |
|----------|-----------------|----------------------|------------------------|
| **Алгоритм** | Все пары точек | Swing-экстремумы | Адаптивное сглаживание |
| **Задержка** | 0-1 свеча | 2-3 свечи | **~0 свечей** |
| **Сложность настройки** | Низкая | Средняя | Высокая |
| **Чувствительность** | Очень высокая | Средняя | **Высокая + адаптивная** |
| **Точность** | Средняя | Высокая | **Очень высокая** |
| **Ложные срабатывания** | Много | Мало | **Очень мало** |
| **Пропущенные движения** | Мало | Средне | **Очень мало** |
| **Монотонные тренды** | ✅ Да | ❌ Нет | **✅ Да** |
| **Структура рынка** | ❌ Нет | ✅ Да | ❌ Нет |
| **Боковик/флэт** | ❌ Шумит | ✅ Фильтрует | **✅ Фильтрует** |
| **Быстрые pumps** | ✅ Ловит | ❌ Может пропустить | **✅ Ловит** |
| **CPU нагрузка** | O(n²) | O(n) + O(s²) | **O(n)** |
| **Память** | Низкая | Низкая | **Средняя (состояния)** |
| **Настройка "из коробки"** | ✅ Да | ✅ Да | ⚠️ Может требовать |
| **Адаптивность** | ❌ Нет | ❌ Нет | **✅ Да** |
| **Теоретическая основа** | Brute-force | Price Action | **Теория оптимального оценивания** |

## 🎯 Когда использовать каждый метод

### v2.4 All Points (Close-based + Confirmation)

```bash
USE_KALMAN_FILTER=false
SWING_LOOKBACK=0  # не используется
MIN_MOVEMENT_DURATION_MS=30000
CONFIRMATION_POINTS=2
USE_CLOSE_CONFIRMATION=true
```

**Лучше всего для:**
- ✅ Максимальная чувствительность
- ✅ Мем-коины и новые листинги
- ✅ News-driven pumps
- ✅ Низкая ликвидность
- ✅ Быстрое прототипирование

**Проблемы:**
- ❌ Много ложных срабатываний на боковике
- ❌ Детектирует случайные движения
- ❌ Требует много фильтрации

---

### v3.0 Swing Detection (Structural Analysis)

```bash
USE_KALMAN_FILTER=false
SWING_LOOKBACK=2
MIN_MOVEMENT_DURATION_MS=30000
CONFIRMATION_POINTS=2
USE_CLOSE_CONFIRMATION=true
```

**Лучше всего для:**
- ✅ Классический трейдинг
- ✅ Следование структуре рынка
- ✅ BTC, ETH, топ-100
- ✅ Среднесрочные стратегии (15+ мин)
- ✅ Минимизация ложных срабатываний

**Проблемы:**
- ❌ Задержка 2-3 свечи
- ❌ Пропускает монотонные тренды
- ❌ Требует swing-структуру (коррекции)

---

### **v4.0 Kalman Filter (Zero-Lag, рекомендуется!)** 🚀

```bash
USE_KALMAN_FILTER=true
KALMAN_PROCESS_NOISE=0.01
KALMAN_MEASUREMENT_NOISE=0.1
KALMAN_SPIKE_THRESHOLD=3.0
MIN_MOVEMENT_DURATION_MS=30000
```

**Лучше всего для:**
- ✅ **Минимальная задержка (zero-lag)**
- ✅ **Быстрые таймфреймы (1-5 мин)**
- ✅ **Монотонные тренды**
- ✅ **Адаптивность к рынку**
- ✅ **Скальпинг**
- ✅ **BTC/ETH и волатильные пары**
- ✅ **Профессиональный трейдинг**

**Проблемы:**
- ❌ Сложнее настроить (требует понимания Q, R)
- ❌ Требует больше памяти (состояния фильтров)
- ❌ Может требовать подстройки под актив

## 📈 Практические примеры

### Пример 1: Ваш график (+4.11% за 32 мин)

**Устойчивый рост с чёткой структурой**

| Метод | Детектирует? | Задержка | Точность |
|-------|--------------|----------|----------|
| All Points | ✅ +4.11% | 0 свечей | Средняя |
| Swing Detection | ✅ +4.11% | 2-3 свечи | Высокая |
| **Kalman Filter** | **✅ +4.11%** | **0 свечей** | **Очень высокая** |

**Победитель:** Kalman (zero-lag + высокая точность)

---

### Пример 2: Боковик с всплеском

**100 → 101 → 105 (спайк) → 101 → 100**

| Метод | Детектирует? | Ложное срабатывание? |
|-------|--------------|----------------------|
| All Points | ✅ +5% | ❌ Да (ложное) |
| Swing Detection | ❌ Нет | ✅ Правильно |
| **Kalman Filter** | **❌ Нет** | **✅ Правильно** |

**Победитель:** Swing / Kalman (фильтруют спайк)

---

### Пример 3: Быстрый pump без откатов

**100 → 103 → 106 → 109 → 112 (за 30 сек)**

| Метод | Детектирует? | Задержка |
|-------|--------------|----------|
| All Points | ✅ +12% | 0 свечей |
| Swing Detection | ❌ Нет | N/A (нет swing) |
| **Kalman Filter** | **✅ +12%** | **0 свечей** |

**Победитель:** All Points / Kalman (Swing пропускает)

---

### Пример 4: Флэт с шумом

**100 → 101 → 100 → 101.5 → 99.5 → 101**

| Метод | Детектирует? | Шум? |
|-------|--------------|------|
| All Points | ✅ +2% | ❌ Да |
| Swing Detection | ❌ Нет | ✅ Фильтрует |
| **Kalman Filter** | **❌ Нет** | **✅ Фильтрует** |

**Победитель:** Swing / Kalman (игнорируют шум)

## 🏆 Рекомендации по выбору

### Для скальпинга (1-5 мин):

```
1️⃣ Kalman Filter (zero-lag + адаптивность)
2️⃣ All Points (если Kalman сложно настроить)
3️⃣ Swing Detection (слишком медленно)
```

### Для дневного трейдинга (15-60 мин):

```
1️⃣ Kalman Filter (оптимальный баланс)
2️⃣ Swing Detection (структурный анализ)
3️⃣ All Points (слишком шумно)
```

### Для свинг-трейдинга (часы/дни):

```
1️⃣ Swing Detection (структура рынка)
2️⃣ Kalman Filter (можно с консервативными параметрами)
3️⃣ All Points (не подходит)
```

### Для мем-коинов и новых листингов:

```
1️⃣ Kalman Filter (адаптивность + zero-lag)
2️⃣ All Points (максимальная чувствительность)
3️⃣ Swing Detection (может пропустить быстрые движения)
```

## 💡 Гибридная стратегия

### Вариант 1: По таймфреймам

```typescript
if (timeframe <= 5) {
  USE_KALMAN_FILTER=true  // 1-5 мин
} else if (timeframe <= 30) {
  USE_KALMAN_FILTER=true  // 5-30 мин (консервативные параметры)
} else {
  USE_KALMAN_FILTER=false  // 30+ мин (Swing Detection)
}
```

### Вариант 2: По активам

```typescript
if (symbol in ['BTC', 'ETH', 'BNB']) {
  USE_KALMAN_FILTER=true  // ликвидные пары
} else if (marketCap > 1B) {
  USE_KALMAN_FILTER=false  // средние (Swing)
} else {
  USE_KALMAN_FILTER=true  // альткоины (адаптивность важна)
}
```

- ✅ Математически обоснован
- ✅ Используется профессионалами
