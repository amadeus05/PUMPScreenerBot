# 🚀 Kalman Filter: Zero-Lag Noise Reduction

## Что это?

**Фильтр Калмана** - математический алгоритм из навигации ракет и GPS, адаптированный для детектирования движений цены криптовалют.

## 🎯 Главное преимущество

**НУЛЕВАЯ ЗАДЕРЖКА** (zero-lag) по сравнению со Swing Detection или скользящими средними!

### Сравнение задержек:

| Метод | Задержка | Точность |
|-------|----------|----------|
| Swing Detection | 2-3 свечи | Высокая |
| Moving Average (MA) | 5-20 свечей | Средняя |
| **Kalman Filter** | **~0 свечей** | **Очень высокая** |

## 🧠 Как это работает

### Концепция:

Фильтр Калмана имеет **"модель инерции"** цены:

1. **Predict** (предсказание): "Где должна быть цена по модели?"
2. **Update** (обновление): "Где цена на самом деле?"
3. **Innovation** (инновация): Разница между предсказанием и реальностью

```
Если Innovation большая → это шум/спайк
Если Innovation маленькая → это реальное движение
```

### Математика (упрощённо):

```typescript
// Шаг 1: PREDICT
x_predicted = x_previous  // предполагаем, что цена сохраняется
P_predicted = P_previous + Q  // Q = шум процесса

// Шаг 2: UPDATE
innovation = measurement - x_predicted  // насколько отличается
K = P_predicted / (P_predicted + R)  // K = Kalman Gain, R = шум измерения

x_new = x_predicted + K * innovation  // взвешенная комбинация
P_new = (1 - K) * P_predicted  // обновляем неопределённость
```

### Kalman Gain (K):

- **K близко к 1** → доверяем измерению (новой цене)
- **K близко к 0** → доверяем модели (игнорируем выброс)

## 📊 Визуальное объяснение

### Пример 1: Реальное движение

```
Цена:    100 → 101 → 102 → 103 → 104
Kalman:  100 → 101 → 102 → 103 → 104

Innovation: маленькая стабильная
K ≈ 0.7 (доверяем измерениям)
✅ Детектирует: +4%
```

### Пример 2: Спайк

```
Цена:    100 → 101 → 110 (спайк!) → 102 → 103
Kalman:  100 → 101 → 103 → 102 → 103

Innovation: огромная на 110!
K ≈ 0.1 (не доверяем выбросу)
✅ Спайк отфильтрован, детектирует: +3%
```

### Пример 3: Монотонный рост (проблема Swing Detection)

```
Цена:    100 → 102 → 104 → 106 → 108
Swing:   ❌ Нет swing-структуры (пропускает)
Kalman:  ✅ 100 → 102 → 104 → 106 → 108

✅ Kalman детектирует: +8%
```

## ⚙️ Настройка

### Добавьте в `.env`:

```bash
# Включить Kalman Filter
USE_KALMAN_FILTER=true

# Шум процесса (насколько быстро меняется цена)
# Больше = более чувствительно к изменениям
# Меньше = более гладкая линия
KALMAN_PROCESS_NOISE=0.01

# Шум измерения (насколько точны данные)
# Больше = меньше доверяем измерениям
# Меньше = больше доверяем измерениям
KALMAN_MEASUREMENT_NOISE=0.1

# Порог спайка (в стандартных отклонениях)
# 3.0 = классический порог (99.7% данных)
# 2.0 = строже (95% данных)
# 4.0 = мягче
KALMAN_SPIKE_THRESHOLD=3.0

# Минимальная длительность (всё ещё применяется)
MIN_MOVEMENT_DURATION_MS=30000
```

## 🔬 Как подобрать параметры

### 1. KALMAN_PROCESS_NOISE (Q)

**Эксперимент:** Наблюдайте за Kalman-линией на графике

```
Слишком большой Q:
- Kalman дёргается вместе с ценой
- Не фильтрует шум
→ Уменьшите Q

Слишком маленький Q:
- Kalman отстаёт от цены
- Пропускает быстрые движения
→ Увеличьте Q

Правильный Q:
- Kalman плавно следует за трендом
- Игнорирует выбросы
```

### 2. KALMAN_MEASUREMENT_NOISE (R)

**Эксперимент:** Смотрите на количество отфильтрованных спайков

```
Слишком большой R:
- Фильтр не доверяет измерениям
- Может пропустить реальные движения
→ Уменьшите R

Слишком маленький R:
- Фильтр слишком доверяет измерениям
- Пропускает спайки
→ Увеличьте R

Правильный R:
- Спайки фильтруются (kalmanSpikes > 0)
- Реальные движения детектируются
```

### 3. KALMAN_SPIKE_THRESHOLD

**Правило:** Используйте статистическое распределение

```
3.0σ → 99.7% данных нормальны, 0.3% - спайки (рекомендуется)
2.5σ → 98.8% данных нормальны, 1.2% - спайки (строже)
2.0σ → 95.4% данных нормальны, 4.6% - спайки (очень строго)
4.0σ → 99.99% данных нормальны (мягко)
```

## ⚡ Преимущества Kalman Filter

### ✅ Что решает:

1. **Zero-lag** - нет задержки детектирования
2. **Монотонные тренды** - детектирует рост без откатов
3. **Адаптивность** - автоматически подстраивается под рынок
4. **Математическая обоснованность** - оптимальный алгоритм оценки
5. **Спайк-детектирование** - автоматически находит выбросы

### ❌ Недостатки:

1. **Сложность настройки** - требует понимания параметров Q, R
2. **Модель** - предполагает "инерцию" цены (не всегда верно для крипты)
3. **Overfitting** - может быть слишком чувствительным к параметрам

## 🆚 Kalman vs Swing Detection

### Используйте Kalman Filter если:

✅ Нужна минимальная задержка  
✅ Торгуете на быстрых таймфреймах (1-5 мин)  
✅ Цена часто движется монотонно  
✅ Важна каждая секунда  
✅ Готовы настраивать параметры  

### Используйте Swing Detection если:

✅ Нужна максимальная точность  
✅ Торгуете на средних/длинных таймфреймах (15+ мин)  
✅ Хотите следовать структуре рынка  
✅ Нужна "из коробки" работа без настройки  
✅ Важнее качество, чем скорость  

## 🎓 Теоретическая основа

Фильтр Калмана изобретён в 1960 году Рудольфом Калманом для:
- Навигации космических кораблей Apollo
- GPS-систем
- Автопилотов самолётов
- Роботов и дронов

**Применение в финансах:**
- Оценка "истинной" цены актива
- Фильтрация рыночного шума
- Предсказание краткосрочных движений
- Высокочастотный трейдинг (HFT)

## 💡 Совет

Начните с **дефолтных настроек**:

```bash
USE_KALMAN_FILTER=true
KALMAN_PROCESS_NOISE=0.01
KALMAN_MEASUREMENT_NOISE=0.1
KALMAN_SPIKE_THRESHOLD=3.0
MIN_MOVEMENT_DURATION_MS=30000
```

Если видите проблемы:
- Много спайков пропускается → уменьшите SPIKE_THRESHOLD
- Пропускает движения → увеличьте PROCESS_NOISE
- Слишком много фильтрует → увеличьте MEASUREMENT_NOISE
