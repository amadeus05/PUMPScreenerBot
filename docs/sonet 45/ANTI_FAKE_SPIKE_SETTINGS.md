# 🚀 Swing Low → Swing High Detector (v3.0)

## Проблема
Предыдущие версии ловили кратковременные выбросы цены (хвостики свечей) или измеряли движения между случайными точками, что приводило к ложным срабатываниям.

## Решение (v3.0) - Правильный Pump-Алгоритм

### 📈 Концепция Swing Detection:

**Swing Low** = Локальный минимум (точка ниже N свечей слева и справа)
**Swing High** = Локальный максимум (точка выше N свечей слева и справа)

Алгоритм детектирует движения **только** от подтверждённых экстремумов к экстремумам, игнорируя шум и случайные точки.

### 🎯 Четыре уровня защиты:

#### 1. **Swing Detection** (Детектирование локальных экстремумов) - НОВОЕ! 🆕
```bash
SWING_LOOKBACK=2  # количество свечей для подтверждения экстремума
```
- **Swing Low**: точка, которая ниже чем N свечей слева и справа
- **Swing High**: точка, которая выше чем N свечей слева и справа
- Движение измеряется ТОЛЬКО от swing low к swing high (pump) или от swing high к swing low (dump)
- Исключает измерения между случайными точками

#### 2. **Close-Based Detection** (Фокус на цене закрытия)
- Используются только цены закрытия бакетов (close)
- Игнорируются высокие/низкие точки (high/low) - именно там находятся хвостики
- Самый стабильный индикатор реального движения

#### 3. **Minimum Duration Filter** (Минимальная длительность)
```bash
MIN_MOVEMENT_DURATION_MS=30000  # по умолчанию 30 секунд
```
- Игнорирует мгновенные всплески
- Движение должно длиться минимум указанное время
- Фильтрует шум и кратковременные выбросы

#### 4. **Confirmation Filter** (Фильтр подтверждения)
```bash
CONFIRMATION_POINTS=2           # количество точек подтверждения
USE_CLOSE_CONFIRMATION=true     # включить подтверждение
```
- После swing-экстремума цена должна подтвердить движение
- Проверяет следующие N точек
- Для pump: цена не падает сильно ниже swing high
- Для dump: цена не растёт сильно выше swing low

## ⚙️ Настройка через .env

```bash
# Swing Detection (локальные экстремумы)
SWING_LOOKBACK=2                 # свечей для подтверждения экстремума

# Минимальная длительность движения (мс)
MIN_MOVEMENT_DURATION_MS=30000

# Количество точек для подтверждения движения
CONFIRMATION_POINTS=2

# Использовать фильтр подтверждения (true/false)
USE_CLOSE_CONFIRMATION=true
```

## 📊 Рекомендуемые настройки

### Для короткого таймфрейма (1-2 минуты):
```bash
SWING_LOOKBACK=1                 # более чувствительно к локальным экстремумам
MIN_MOVEMENT_DURATION_MS=15000   # 15 секунд
CONFIRMATION_POINTS=1
USE_CLOSE_CONFIRMATION=true
```

### Для среднего таймфрейма (5-15 минут):
```bash
SWING_LOOKBACK=2                 # сбалансированное определение экстремумов
MIN_MOVEMENT_DURATION_MS=30000   # 30 секунд
CONFIRMATION_POINTS=2
USE_CLOSE_CONFIRMATION=true
```

### Для длинного таймфрейма (30+ минут):
```bash
SWING_LOOKBACK=3                 # более строгое определение экстремумов
MIN_MOVEMENT_DURATION_MS=60000   # 60 секунд
CONFIRMATION_POINTS=3
USE_CLOSE_CONFIRMATION=true
```

### Максимально агрессивная (ловит все движения):
```bash
SWING_LOOKBACK=1                 # минимальное подтверждение экстремумов
MIN_MOVEMENT_DURATION_MS=5000    # 5 секунд
CONFIRMATION_POINTS=0
USE_CLOSE_CONFIRMATION=false
```

## 🔍 Как это работает

### Пример 1: Swing Detection (v3.0)

```
Свечи (SWING_LOOKBACK=2):
10:00:00 - Close: 102$
10:01:00 - Close: 100$  ← ниже соседей слева и справа
10:02:00 - Close: 101$
10:03:00 - Close: 103$
10:04:00 - Close: 106$
10:05:00 - Close: 108$  ← выше соседей слева и справа
10:06:00 - Close: 107$

Swing Low:  100$ (10:01:00) ✓
Swing High: 108$ (10:05:00) ✓

✅ Детектирует: +8% от swing low к swing high
```

### Пример 2: Фейковый скачок (отфильтрован)

```
Свечи:
10:00:00 - Close: 100$
10:00:15 - Close: 105$ (не является swing high - нет подтверждения)
10:00:30 - Close: 100.5$ (цена вернулась)
10:00:45 - Close: 101$

❌ Swing High не обнаружен (105$ не выше соседних на SWING_LOOKBACK)
❌ Движение не детектируется
```

### Пример 3: Реальный Pump

```
Свечи (последовательный рост):
10:00:00 - Close: 100$  ← Swing Low
10:01:00 - Close: 101$
10:02:00 - Close: 103$
10:03:00 - Close: 105$
10:04:00 - Close: 107$
10:05:00 - Close: 108$  ← Swing High
10:06:00 - Close: 107$
10:07:00 - Close: 106$

✅ Swing Low: 100$
✅ Swing High: 108$ 
✅ Длительность: 5 минут (> 30 секунд)
✅ Подтверждено: цена удержалась выше 100$
✅ Детектирует: +8% pump
```

## 🚀 Преимущества v3.0

1. ✅ **Swing Detection** - измеряет от реальных экстремумов (правильный pump-алгоритм)
2. ✅ Фильтрует хвостики свечей (close-based)
3. ✅ Игнорирует кратковременные всплески (min duration)
4. ✅ Требует подтверждения swing-движения
5. ✅ Работает с реальными ценами закрытия
6. ✅ Гибкая настройка под любой таймфрейм
7. ✅ Не пропускает настоящие pump/dump движения
8. ✅ Детектирует только подтверждённые локальные экстремумы

## ⚠️ Важно

- Слишком строгие настройки могут пропускать быстрые движения
- Слишком мягкие настройки будут ловить фейковые скачки
- Рекомендуется начать со средних значений и корректировать по результатам
- Для разных символов могут потребоваться разные настройки
