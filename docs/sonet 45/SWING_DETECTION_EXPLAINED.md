# 🎯 Swing Low → Swing High Detector: Полное объяснение

## Что такое Swing Detection?

**Swing Detection** - это алгоритм из технического анализа для определения **локальных экстремумов** (минимумов и максимумов) на графике цены.

### Основные концепции:

1. **Swing Low (Локальный минимум)** - точка, которая **ниже** чем N свечей до и после неё
2. **Swing High (Локальный максимум)** - точка, которая **выше** чем N свечей до и после неё

## 📊 Визуальное объяснение

```
Пример с SWING_LOOKBACK=2:

      108$ ← Swing High (выше 2 свечей слева и 2 справа)
     /  \
   106$ 107$
   /      \
 103$     105$
 /         \
100$ 101$ 102$
  ↑
  Swing Low (ниже 2 свечей слева и 2 справа)
```

## 🔬 Как работает алгоритм

### Шаг 1: Определение Swing Lows

```typescript
Для каждой свечи i (от SWING_LOOKBACK до length - SWING_LOOKBACK):
  Проверить:
    - Цена[i] < Цена[i-1] И
    - Цена[i] < Цена[i-2] И
    - Цена[i] < Цена[i+1] И
    - Цена[i] < Цена[i+2]
  
  Если ВСЕ условия выполнены → это Swing Low ✓
```

**Пример:**
```
Свечи: 102, 101, 100, 101, 103
         ↑    ↑    ↑    ↑    ↑
        i-2  i-1   i   i+1  i+2

100 < 101 (i-1) ✓
100 < 102 (i-2) ✓
100 < 101 (i+1) ✓
100 < 103 (i+2) ✓

→ 100$ это Swing Low!
```

### Шаг 2: Определение Swing Highs

```typescript
Для каждой свечи i:
  Проверить:
    - Цена[i] > Цена[i-1] И
    - Цена[i] > Цена[i-2] И
    - Цена[i] > Цена[i+1] И
    - Цена[i] > Цена[i+2]
  
  Если ВСЕ условия выполнены → это Swing High ✓
```

**Пример:**
```
Свечи: 103, 106, 108, 107, 105
         ↑    ↑    ↑    ↑    ↑
        i-2  i-1   i   i+1  i+2

108 > 106 (i-1) ✓
108 > 103 (i-2) ✓
108 > 107 (i+1) ✓
108 > 105 (i+2) ✓

→ 108$ это Swing High!
```

### Шаг 3: Поиск лучшего движения

```typescript
// PUMP: Swing Low → Swing High
Для каждого Swing Low:
  Для каждого Swing High ПОСЛЕ него:
    Если длительность >= MIN_MOVEMENT_DURATION_MS:
      Если подтверждено (USE_CLOSE_CONFIRMATION):
        Посчитать процент роста
        Запомнить лучший
```

```typescript
// DUMP: Swing High → Swing Low
Для каждого Swing High:
  Для каждого Swing Low ПОСЛЕ него:
    Если длительность >= MIN_MOVEMENT_DURATION_MS:
      Если подтверждено (USE_CLOSE_CONFIRMATION):
        Посчитать процент падения
        Запомнить лучший
```

## 🎮 Влияние параметра SWING_LOOKBACK

### SWING_LOOKBACK=1 (Агрессивный)

```
Требует подтверждения только от 1 свечи с каждой стороны

Свечи: 101, 100, 101
           ↑
      Swing Low ✓

→ Больше swing-точек
→ Более чувствителен
→ Может ловить небольшие колебания
```

### SWING_LOOKBACK=2 (Сбалансированный)

```
Требует подтверждения от 2 свечей с каждой стороны

Свечи: 103, 101, 100, 101, 102
               ↑
          Swing Low ✓

→ Средняя чувствительность
→ Фильтрует мелкие колебания
→ Ловит значимые экстремумы
```

### SWING_LOOKBACK=3 (Консервативный)

```
Требует подтверждения от 3 свечей с каждой стороны

Свечи: 105, 103, 102, 100, 101, 102, 103
                   ↑
              Swing Low ✓

→ Меньше swing-точек
→ Только явные экстремумы
→ Минимум ложных срабатываний
```

## 💡 Почему это лучше предыдущего подхода?

### ❌ Старый подход (все точки):

```
Измеряет движение между ЛЮБЫМИ двумя точками:

100$ → 101$ → 105$ → 102$ → 108$

Может найти:
- 100$ → 108$ (+8%) ✓
- 101$ → 108$ (+6.9%)
- 102$ → 105$ (+2.9%)
- 105$ → 102$ (-2.9%)

Проблема: много шума, случайные точки
```

### ✅ Новый подход (Swing Detection):

```
Измеряет движение ТОЛЬКО между swing-экстремумами:

100$ (Swing Low) → 108$ (Swing High)

Находит ТОЛЬКО:
- 100$ → 108$ (+8%) ✓

Преимущество: только значимые движения
```

Используется профессиональными трейдерами для:
- Определения структуры рынка
- Поиска точек входа/выхода
- Анализа трендов
- Детектирования разворотных паттернов
