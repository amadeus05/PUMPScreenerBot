            ┌──────────────────────────────────────────┐
            │            INPUT: приход цены            │
            └──────────────────────────────────────────┘
                              │
                              ▼
                 ┌────────────────────────┐
                 │ Собрать данные окна    │
                 │ (15s/1m buckets)       │
                 └────────────────────────┘
                              │
                              ▼
                 ┌────────────────────────┐
                 │    Вычислить окно      │
                 │  [now - W; now]        │
                 └────────────────────────┘
                              │
                              ▼
        ┌─────────────────────────────────────────────────────────┐
        │                   ВЕТВЛЕНИЕ ПО РЕЖИМУ                   │
        └─────────────────────────────────────────────────────────┘

========================================================================================
=                                      CLASSIC                                         =
========================================================================================
              Логика: Price(now) - Price(now - W)
                          │
                          ▼
        ┌──────────────────────────────────────────┐
        │  P1 = price(now)                         │
        │  P0 = interpolated price(now - W)        │
        │  Δ% = (P1 - P0) / P0 * 100               │
        └──────────────────────────────────────────┘
                          │
                          ▼
                 ┌───────────────────────┐
                 │ Δ% ≥ threshold ?      │───► YES → Сигнал
                 └───────────────────────┘
                          │
                          └──► NO → Нет сигнала


========================================================================================
=                                      EXTREMES                                        =
========================================================================================
         Логика: max(window) / min(window) независимо от позиций
                              │
                              ▼
            ┌────────────────────────────────────────┐
            │ minP = минимум цены в окне             │
            │ maxP = максимум цены в окне             │
            │ rise% = (maxP - minP)/minP * 100        │
            │ drop% = (maxP - minP)/maxP * 100        │
            └────────────────────────────────────────┘
                              │
                              ▼
                 ┌───────────────────────┐
                 │ max(rise%, drop%) ≥   │
                 │        threshold ?     │──► YES → Сигнал
                 └───────────────────────┘
                              │
                              └──► NO → Нет сигнала


========================================================================================
=                                       HYBRID                                         =
========================================================================================
          Логика: CLASSIC + EXTREMES → выбрать лучший
                              │
                              ▼
      ┌──────────────────────────────┐
      │ Вычислить classicΔ%          │
      │ Вычислить extremesΔ%         │
      └──────────────────────────────┘
                  │
                  ▼
     ┌─────────────────────────────────────────────┐
     │ 1) Если extremesΔ% >= threshold             │
     │     И extremesΔ% > classicΔ%                │
     │     → брать EXTREMES                        │
     │                                             │
     │ 2) Иначе                                    │
     │     → брать CLASSIC                         │
     └─────────────────────────────────────────────┘
                  │
                  ▼
     ┌──────────────────────────┐
     │ Δ% (финальное) ≥ порог ? │──► YES → Сигнал
     └──────────────────────────┘
                  │
                  └──► NO → Нет сигнала


========================================================================================
=                                ДОПОЛНИТЕЛЬНЫЕ УСЛОВИЯ                                 =
========================================================================================
Все режимы учитывают:
  • warmup (нет 20 минут истории → сигнал блокируется)
  • отсутствие данных → пропуск
  • интерполяцию границ окна (нормализует P0)
  • LRU очистку старых символов
  • 15s + 1m buckets одновременно
  • нет race conditions, нет утечек памяти
